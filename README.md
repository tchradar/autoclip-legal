## Wishlist Elf (`christmas-list/`)
A mobile Christmas list idea generator. Pick an age group, the categories
someone is into, and optionally a budget, and it suggests gift ideas. Tap ♡ to
save an idea to "My List", add your own, check items off, and share the list.

It's an installable web app (PWA) that works offline. Open
`christmas-list/index.html` from GitHub Pages on your phone, then choose
"Add to Home Screen". To run it locally: `cd christmas-list && python3 -m http.server`.
Gift ideas live in `christmas-list/gifts.js`.
